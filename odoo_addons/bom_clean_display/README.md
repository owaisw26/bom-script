# BoM Clean Product Display

This Odoo 18 add-on hides product Internal References such as `[3DX-prd-…]` in the Bill of
Materials list, finished-product field, and component table. It does not delete or change the
Internal Reference, so imports and product searches can continue to use it.

Add `odoo_addons` to the Odoo add-ons path, update the Apps list, and install
**BoM Clean Product Display**. This requires Odoo.sh or an on-premise Odoo deployment that permits
custom modules. Odoo Online Standard does not support installing this add-on.
